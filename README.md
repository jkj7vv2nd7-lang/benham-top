# ベンハムのコマ工作キット

白黒の円盤を回すと淡い色が見える「ベンハムのコマ（ベンハムの円盤）」の工作キット。単体HTMLアプリ（自己完結・CDN不使用）。

## ファイル
- `index.html` — アプリ本体（絵柄6種・型紙・画面での試し回し・説明書・印刷用画像の書き出し）
- `icon.png` / `icon-180.png` — ホーム画面アイコン（自作描画）
- `verify.js` — 自動検証（起動・幾何・PNG実寸測定）
- `shot.js` — プレビュー画像の生成（確認用）

## 仕様
- 絵柄は全6種のオリジナル（古典柄の複製ではない）。扇形と円弧の配置・長さ・組数を変えた組み合わせで、各柄に名前と「見えやすい色の傾向（目安）」付き
  1. 朝焼けアーチ（赤〜橙系）2. 青い二重輪（青〜緑系）3. 渦巻きの尾（紫〜青系）4. 四つ葉の交差（緑〜黄系）5. 反転リング（赤みと青み）6. うろこ模様（淡い混合色）
  - 絵柄はすべてベクター（SVG）で描画。円弧の帯の厚みは半径比0.06以上（CD円盤で3.5mm以上）を確保し、印刷で潰れない太さにしてある
- 型紙は1ページに2形式：CD／DVD用（直径120mm・中心穴15mm）と心棒用（直径100mm・中心マークつき）。A4縦・100%実寸、赤い5cm較正線つき。選んだ絵柄で両形式が描かれる
- 印刷：ピンホールカメラ工作キットで実機確認の取れた方式（アプリが各ページを300dpi PNG画像として書き出す。写真と同じ印刷経路で出せる）
- 画面での試し回し：速度（毎秒1〜12回転）と回転方向を変えてプレビューできる（表示の限界があり実物とは色の出方が違う旨を明記）
- 説明書：作り方（中心の正確さ、気泡を入れない貼り方、心棒の立て方、CDの回し方）、見方のコツ（明るい白色光、毎秒5〜10回転、逆回転で色が入れ替わる、見えないときの調整）、解説（フェヒナー1838年の主観色、1894年のベンハムの玩具、錐体の応答時間差という有力説と未解明である旨、個人差）、ちらつきへの注意

## 検証済み（verify.js 全項目合格）
- 起動・ページエラー0、幾何110項目（円の直径120/100mm・中心穴15mmの定数、絵柄ごとの扇形・円弧の妥当性、全ページの収納と非重なり、較正線50mm）
- PNG書き出しの実測：CD円盤の直径 120.31mm、心棒円盤 100.33mm、中心穴の縁は中心から約7.4mm（いずれも線幅分を含む実測で実寸どおり）、較正線596px（50mm相当）
- 全6絵柄×3ページの描画、試し回しの再生・方向・速度の切替
